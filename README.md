# 🔗 notificator
Работа с брокером сообщений. `Spring Boot`, `Kafka`, `Docker`, `Gradle`.
Содержит несколько модулей.

### ⚙️ common
Общие классы.

### 📝 notification
Сервис отправки уведомлений в брокер сообщений.

### 🚀 gateway
Сервис, эмулирующий отправку `SMS` и `E-mail`, которые он получает из брокера сообщений.
